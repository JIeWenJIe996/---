# 学习通答题助手

一个 Tampermonkey 用户脚本，用来读取学习通页面上的题目，调用 DeepSeek 或兼容接口，展示参考答案和解析。支持单选、多选、判断，以及普通输入框中的填空、简答题。

可以逐题回填，也可以开启自动回填；脚本不会自动提交。遇到映射字体或图片题时，可以通过本地 OCR 或手动截图处理。

## 安装

1. 在 Edge、Chrome 等浏览器中安装并启用 Tampermonkey。
2. 打开 [大肥鱼学习无痛助手.js](大肥鱼学习无痛助手.js)，复制完整代码。
3. 在 Tampermonkey 中新建脚本，替换默认内容并保存。
4. 刷新学习通页面，点击右下角的“答题助手”。入口和面板都可以拖动，位置会自动保存。

当前版本为 `0.6.2`，匹配 `https://*.chaoxing.com/*` 和 `https://*.edu.cn/*`。安装时只需要上面的 JS 文件，不需要运行 Node.js。

## 配置接口

展开“API 设置”，填写自己的 API Key、接口地址和模型名。修改后自动保存；“保存并检查地址”只检查地址格式，不会测试连通性。

| 设置 | 用法 |
| --- | --- |
| API Key | 所用接口平台提供的密钥 |
| API 地址 | 默认 `https://api.deepseek.com/chat/completions`，必须使用 HTTPS |
| 文本模型 | 填写平台实际支持的模型名；脚本预填的 `deepseek-flash` 不代表接口一定支持 |
| 思考强度 | 默认“高”，可选关闭、低、高、最高；是否支持取决于平台和模型 |
| 温度 | 默认 `0.1`，范围 `0–2`，只在关闭思考时发送 |
| 截图用视觉模型 | 直接发送图片时需要填写，使用同一 API 地址和密钥 |

接口地址可以填完整的 `/chat/completions` 地址，也可以填域名根地址或以 `/v1` 结尾的地址，脚本会补全路径。地址不能带账号、查询参数或 `#` 片段。

使用其他平台时，在脚本顶部添加对应域名的连接权限，例如：

```js
// @connect      api.example.com
```

保存后按 Tampermonkey 的提示允许连接。接口需要兼容 Chat Completions，并能返回脚本要求的 JSON 答案。请求中还包含 `thinking` 参数，开启思考时会发送 `reasoning_effort`；并非所有兼容接口都接受这些字段。遇到 HTTP 400，可以先关闭思考重试，如果仍报错，需要核对平台的参数要求。

## 使用

1. 打开题目页面，等题干和选项加载完成。
2. 点击“识别预览”，展开题目检查识别内容。
3. 点击“获取答案”。脚本每批最多处理 3 题，结果显示在原题下方和面板的“答案结果”中。
4. 核对答案后点击“回填本题”。需要自动填写时，提前勾选“取得答案后自动回填”。

点击“停止”会中止当前 API 请求和后续处理。OCR 会在当前阶段结束后停止，可能需要稍等。

脚本会扫描当前页面和可访问的同源 iframe。跨域 iframe 由其中的脚本实例提供入口；如果没有识别到题目，可以检查框架内是否有另一个“答题助手”，或者使用手动输入。

## 乱码和截图

部分学习通页面使用映射字体：屏幕上看起来正常，复制出来却是乱码。“使用字体映射处理（自动 OCR）”默认开启，检测到这类题目后，脚本会用网页原字体绘制图片，在浏览器中识别文字，再将文字发送给模型。关闭这个开关只会直接读取网页文字，不能修复乱码。

如果自动识别失败，展开“手动文本 / 题目截图”：

1. 导入或粘贴单题截图，支持 PNG、JPEG、WebP，文件不超过 5 MB。
2. 点击“本地 OCR”，核对并修改文本框里的题干和选项。
3. 点击“解析手动题目”。如果需要回填，先选择对应的“回填目标”。

也可以直接粘贴完整的题干和选项。数字、否定词、选项字母和公式容易识别出错，发送前请检查。

需要让模型直接看图时，填写视觉模型并勾选“发送图片”。**导入截图后，这个选项会自动勾选；本地 OCR 成功后会自动取消，只发送文字。** 导入图片本身不会调用模型接口。

“字体字形样本”可以导出当前题目的字形 PNG 和 JSON，用于人工核对字符。导出的内容只是当前页面样本，不能直接作为通用字体解码表。

## 常见问题

**没有入口或识别不到题目**

检查脚本是否启用、当前网址是否在匹配范围内，以及题目是否已经加载。不同版本的学习通页面结构可能不同，无法识别时可改用手动文本或截图。

**接口报错**

401 通常是密钥问题，402 是余额不足，404 需要检查接口路径和模型名，429 表示限流或额度受限。连接被拒绝时，检查脚本中的 `@connect` 和 Tampermonkey 的连接授权。

**OCR 卡住或加载失败**

首次使用需要下载识别组件和中文字库。Tesseract.js 及其 worker、WASM 从 jsDelivr 加载，中文字库来自 `tessdata.projectnaptha.com`。其中任一资源无法访问，都可能导致初始化或识别失败。脚本会尝试重建识别器并重试一次，也可以用其他 OCR 工具识别后粘贴文字。

**有答案，但回填失败**

页面已经换题、选项被禁用、富文本编辑器或无法确认选中状态的控件，都可能导致回填失败。参考答案会保留，请核对后手动填写。图片、复杂公式和特殊题型也可能需要手动处理。

## 数据存储

API Key、接口配置和开关保存在 Tampermonkey 的脚本存储中，面板与入口的位置也会保存。共享浏览器配置时，注意其中留存的密钥。

获取答案时，题干和选项会发送到你配置的 API；解析手动题目时会发送文本框内容，勾选“发送图片”后还会附带截图。本地 OCR 的识别过程在浏览器中执行，不会单独将截图上传给 OCR 服务。

## 文件与检查

- `大肥鱼学习无痛助手.js`：主脚本，包含题目读取、接口请求、回填、OCR 和面板界面。
- `示例.txt`：第三方参考脚本，不是本项目的安装入口。
- `README.md`：安装和使用说明。

修改主脚本后，可以用 Node.js 检查语法：

```sh
node --check "大肥鱼学习无痛助手.js"
```

当前目录没有配套的自动化测试。语法检查通过后，仍需在浏览器中核对题目预览、答案展示、回填和截图 OCR。

## 参考与使用说明

本项目用于学习和技术交流。模型答案和 OCR 结果都需要自行核对，使用时请遵守学校及平台规定，不要用于考试作弊或代考。
